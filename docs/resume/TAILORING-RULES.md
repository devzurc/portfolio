# CV location tailoring rules

The location line in each CV is a per-application placeholder. Tailor it per application. Do not create one file per city.

1. **Default (Curitiba or remote in Brazil):** use `LucasCruz_CV_EN.md` / `LucasCruz_CV_PT.md` as they are.
   - EN: `Curitiba, Paraná, Brazil`
   - PT: `Curitiba, Paraná, Brasil`
2. **Role in another Brazilian city:** in the default EN/PT file, swap only the city/state. Do not save a separate per-city file.
3. **Any other case:** discuss with the owner first. Public CVs, PDFs and site copy carry no relocation or visa line, no phone number and no employer name.

## Where each version lives

- **Repo markdown (`docs/resume/markdown/`):** holds the default Brazil versions.
- **PDFs** are generated from the same wording and served from `assets/files/cv/`.
