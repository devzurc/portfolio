# CV location tailoring rules

The location line in each CV is a per-application placeholder. Tailor it per application. Do not create one file per city.

1. **Default (Curitiba or remote in Brazil):** use `LucasCruz_CV_EN.md` / `LucasCruz_CV_PT.md` as they are.
   - EN: `Curitiba, Paraná, Brazil`
   - PT: `Curitiba, Paraná, Brasil`
   - No visa line.
2. **Role in another Brazilian city (e.g. Florianópolis):** in the default EN/PT file, swap only the city/state, e.g. `Florianópolis, Santa Catarina, Brazil` / `Florianópolis, Santa Catarina, Brasil`. No visa line. Do not save a separate per-city file.
3. **Role outside Brazil:** use the international variant.
   - EN `LucasCruz_CV_EN_intl.md`: `Curitiba, Paraná, Brazil · Open to relocation · Requires visa sponsorship`
   - PT `LucasCruz_CV_PT_intl.md`: `Curitiba, Paraná, Brasil · Aberto a realocação · Requer patrocínio de visto`

## Where each version lives

- **Google Docs (EN and PT):** hold the **international** versions.
- **Repo markdown (`docs/resume/markdown/`):** holds the **default Brazil** versions (no visa line).
- The relocation/visa line is allowed only in the intl files and the Google Docs.
