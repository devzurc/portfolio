# project_etl_heroby

> **Archived** — CLI utility for extracting HeroBy platform data from DynamoDB; supporting wDiscover client-work evidence.

## One-liner

Python CLI that automates DynamoDB exports from a client IoT platform using Boto3, with menu-driven extraction for beacons and gateways.

## Problem

Client platform data needed repeatable extraction from DynamoDB for downstream analysis without manual console exports.

## What I built

- Boto3-based extraction scripts with virtualenv workflow
- Menu-driven exports for beacon and gateway datasets
- Companion to dashboard/reporting automation in `project_dashboard_heroby`
