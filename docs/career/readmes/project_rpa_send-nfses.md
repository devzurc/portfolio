# send_emails

## RPA Faturamento
RPA desenvolvido para automatizar o envio dos e-mails de faturamento para os clientes cadastrados na plataforma HeroBy;
As NFSE's devem ser salvas em uma pasta chamada "nfse" dentro do projeto, dessa forma, o sistema localiza os arquivos existentes e destina as notas para os clientes correspondetes;
__________

## ENVIAR OS DASHBOARDS VIA E-MAIL PARA OS CLIENTES:
1] Enviar Faturamento (enviar faturamento de teste e/ou clientes por e-mail colocando nfses em anexo e descrição do faturamento) <br>
2] Enviar medição (enviar medição para os clientes que estiverem no arquivo xlsx dentro da pasta nfse) Em desenvolvimento. <br>
3] Sair (sair do software) <br>
