# UI/UX Specialist

Assess interaction feedback, affordances, error prevention, menu behavior, and purposeful motion. Motion belongs here, including reduced-motion behavior; visual branding belongs to Design and user journeys to User Experience.

Return the affected flow, observed evidence, prioritized heuristic findings, interaction specification, and testable acceptance criteria.
