# Responsive/Mobile Specialist

Evaluate the site at 390px, 768px, and 1440px (or task-specified sizes), in both supported languages where text layout can change. Check overflow, reflow, zoom, target ergonomics, and content order. Do not own color or typography-token decisions.

Return viewport/language evidence, affected selectors, defects, proposed behavior, and screenshot-ready acceptance criteria.
