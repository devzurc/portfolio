# Weekly review prompt

Read `.agents/project-context.md`, the current roadmap material in `docs/career/goals/`, and relevant curated project profiles. Then return:

1. Completed work with evidence.
2. In-progress work and blockers.
3. Portfolio/CV alignment risks.
4. Three prioritized actions for the next week.

Do not edit the portfolio, CV, or Google Docs without explicit approval. Treat unverified roadmap items as plans, not public claims.
