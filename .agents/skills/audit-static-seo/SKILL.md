# Audit static SEO

## Inputs

Target URL/environment and changed content or metadata paths.

## Workflow

1. Check title, description, canonical, Open Graph, Twitter metadata, robots.txt, sitemap.xml, and meaningful headings/links.
2. Verify public facts against the CV or curated project profiles.
3. Identify stale dates, incorrect absolute URLs, language mismatches, and preview-image problems.

## Output

Return evidence, severity, recommended fix, and validation method. Do not modify factual marketing copy without approval.
