# Add verified project

## Inputs

Curated project profile or CV evidence, public repository/demo/certificate URLs, EN/PT copy, and desired placement.

## Workflow

1. Read `docs/career/projects/` and CV sources; request evidence for missing outcomes, dates, or links.
2. Separate public-safe claims from private/client details and never fabricate metrics.
3. Match the existing project markup and bilingual pattern.
4. Verify link validity, scanability, and responsive layout before QA.

## Output

Return the evidence map, proposed placement, content draft, implementation scope, and acceptance criteria. Public changes require owner approval.
